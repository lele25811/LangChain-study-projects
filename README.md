# LangChain-study-projects
A repo for my LangChain study projects.

The projects are from the course: Introduction to LangChain - Python

### 💪🏻 Module 1 – Personal Fitness Trainer
Development of a personal fitness assistant using **Prompt Templates**, **LLM Chains**, and **structured output**. 
This notebook demonstrates how to build a conversational application capable of generating personalized fitness and wellness recommendations using LangChain's core components.

### ✈️ Module 2 – Travel Planner
Development of a travel planning application based on a **multi-agent** architecture. 
This notebook introduces collaboration between specialized agents, each responsible for a specific subtask, coordinating tools and language models to generate personalized travel itineraries.

### 🏦 Module 3 – Bank Agents
Implementation of a banking assistant following the **Human-in-the-Loop (HITL)** paradigm. 
This notebook demonstrates how to integrate human approval checkpoints into an agent workflow, allowing users to review and authorize sensitive operations before execution, improving the system's reliability and control.
